# E7 route each failure to its source layer

## Goal

Reflection writes prose lessons with no explicit layer decision, which is why a
harness directive can be promoted for what is actually a model-layer problem. The
loop then edits the harness to fix something the harness does not control, and
either the edit fails or it "succeeds" against a probe set that cannot see the
difference.

### Mechanisms (exact spec)

Assign each failure to exactly one of four layers as the first reflection step:
model, recipe-harness, environment-or-tool, kickoff-benchmark. Store it as a typed
field on the reflection record.

`mini_ork/learning/writeback.py` refuses to promote a harness directive sourced
from a non-harness-layer failure, and the refusal is recorded. Harness-layer
failures route to the harness modules of Epic 6, model-layer failures route to
lane re-selection, environment and tool failures route to runtime and tool fixes,
and benchmark failures route to kickoff repair.

The assignment must cite the trace evidence that produced it — the node, the
observation, and the counterfactual if one exists. An uncited layer assignment is
recorded as unclassified rather than guessed.

### Tests

Extend `tests/unit/test_writeback.py`. Assert: a harness directive sourced from a
model-layer failure is refused and the refusal is recorded; an uncited assignment
lands as unclassified; each of the four layers routes to its named destination.

### Self-application measurement

Baseline: replay the last N classified failures and record how many promotions
were layer-mismatched under today's untyped path. After: the same replay under the
typed path. Accepted iff a deliberately mislabeled candidate — a harness directive
sourced from a model-layer failure — is rejected, and the mislabeled-promotion
count over the replay drops to zero.

Evidence artifact: `${MINI_ORK_RUN_DIR}/layer-routing-replay.json` with the
per-failure layer, the routed destination, and the rejection tally.

### Done When

- Every reflection record carries a layer or is explicitly unclassified.
- A layer-mismatched promotion is impossible through the writeback path.
- The replay shows zero mislabeled promotions.
