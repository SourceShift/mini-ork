# E6 point the apply sweep at the harness

## Goal

`mini_ork/cli/apply.py:auto_sweep` selects candidates with `WHERE target LIKE
'agent.%'`, so the sweep only ever proposes prompt and directive edits. The
harness — `workflow.yaml` node order, node prompts, tool grants — is not evolvable
by the loop; changing it is human-driven through recipe-creator and framework-edit.
Point the existing machinery at the harness, one module at a time.

### Mechanisms (exact spec)

Declare explicit harness modules per recipe: planner prompt, verifier gate set,
tool grants, node order. Each is a separately addressable mutation target.

Teach `auto_sweep` and `apply_run` a `harness.<module>` target kind alongside
`agent.*`. One module per candidate; never a multi-module mutation, because a
mutation that changes four things cannot be attributed.

Candidates are graded against the Epic 2 probe set, through the Epic 3
certificate, with the lane pinned by Epic 5 and the edit scope bounded by Epic 4.

### Tests

Extend `tests/unit/test_auto_sweep.py`. Assert: `harness.node_order` is
selectable as a target; a harness candidate flows through `evaluate_gate` and the
certificate path; a multi-module candidate is refused.

### Files in scope

- mini_ork/cli/apply.py
- recipes/*/workflow.yaml (module declarations)
- tests/unit/test_auto_sweep.py

### Self-application measurement

This is the literal self-application epic: the change to mini-ork is proposed by
mini-ork and its value is measured by running mini-ork. Baseline: the pinned probe
set under the current `workflow.yaml`. After: the same probe set under the mutated
node order, same lane, same fixtures. Accepted iff the certificate's lower
confidence bound on the delta is above zero AND the per-task no-regression holds
(`MO_APPLY_PERTASK_JSON`).

Evidence artifact: `${MINI_ORK_RUN_DIR}/harness-mutation-score.json` with the
candidate id, the mutated module, the paired per-task results, and the certificate.

### Done When

- `auto_sweep` can propose a harness-module candidate.
- The candidate is graded by the certificate, not by a point estimate.
- A rejected harness candidate is quarantined, never applied.
