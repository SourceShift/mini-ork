## Found along the way

- The primary checkout's `mini_ork/recovery/auto_repair.py` did not parse
  for 37 minutes: a peer's debug-probe revert used `str.replace` and the
  4-space pattern matched the tail of the 8-space line. Restored to HEAD (its
  only diff); the owner confirmed no run failed in the window.
- `acquire_lease` returns None on any sqlite error, which reads as "lease
  held" to every caller; the scheduled reflect now checks the table first.
- reflect's deadline `SystemExit(124)` was swallowed by the gradient extractor's
  per-trace handler, so the deadline never stopped extraction (post-run reflect
  too); it is now a `ReflectDeadline` the handler re-raises (711ed954).
- An inclusive `since` at second resolution re-selects the boundary second
  every pass; the scheduled window is `(since, until]` (f8b83c49).
